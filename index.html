Quick Start

Up and running
in 3 steps

01

Install

Install globally via npm or pnpm:

bash 
# Using npm
npm install -g @bobmatnyc/ai-code-review

# Using pnpm (recommended)
pnpm add -g @bobmatnyc/ai-code-review
02

Configure API Keys

Create a .env.local file in your project root:

.env.local 
# Model selection
AI_CODE_REVIEW_MODEL=gemini:gemini-2.5-pro

# API Keys (choose your provider)
AI_CODE_REVIEW_GOOGLE_API_KEY=your_key_here
AI_CODE_REVIEW_ANTHROPIC_API_KEY=your_key_here
AI_CODE_REVIEW_OPENROUTER_API_KEY=your_key_here
03

Run Your First Review

Run a comprehensive review of your codebase:

bash 
# Review current directory
ai-code-review . --type comprehensive

# Security review with specific language
ai-code-review src --type security --language typescript

# Estimate tokens & cost first
ai-code-review . --estimate

Library API

Integrate into
your own apps

Use AI Code Review as a Node.js library in Next.js routes, Express servers, or CI/CD pipelines.

typescript 
import { performCodeReview } from '@bobmatnyc/ai-code-review/lib';

const result = await performCodeReview({
  target: './src',
  config: {
    model: 'openrouter:anthropic/claude-3.5-sonnet',
    reviewType: 'security',
    apiKeys: { openrouter: 'your-api-key-here' },
    outputFormat: 'json'
  },
  options: {
    maxFiles: 50,
    onProgress: (progress) => {
      console.log(`${progress.stage}: ${progress.progress}%`);
    }
  }
});

console.log('Review completed:', result);

typescript 
// pages/api/review.ts (Next.js)
import { performCodeReview } from '@bobmatnyc/ai-code-review/lib';

export default async function handler(req, res) {
  try {
    const result = await performCodeReview({
      target: req.body.target,
      config: {
        model: req.body.model,
        apiKeys: {
          openrouter: process.env.OPENROUTER_API_KEY
        }
      }
    });
    res.json(result);
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
}
